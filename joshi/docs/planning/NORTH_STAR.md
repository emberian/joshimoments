# NORTH STAR — what JOSHI is

Pinned 2026-08-25 after the operator re-stated it directly. This document outranks every other
planning doc when they disagree. Her words, near-verbatim: "we should just replicate the
pump.fun experience wholesale, augment it exocortexy, and grow from there." And: "integrate the
agent sdk and claude code sdk directly into the thing so that joshi becomes a self-modifying
self-editing market-analysis thingy."

## The four commitments

1. **Glass is the product.** A live web application that replicates the pump.fun experience
   wholesale: a flowing board, one-click coin pages, a chart that moves, callouts and social
   surfaces, search — with pump.fun's information density and immediacy. Backed by JOSHI's
   honest data layer. "Boop me a mint in chat" is NOT the gesture; the seat is the app.

2. **Augmented, exocortex-y.** Layered onto parity, the things pump.fun cannot have: durable
   holds and journal in her own words, the self-writing debrief, attention instrumentation
   feeding the pre-registered selection instrument, and the microstructure corpus
   (docs/microstructure/trades_quotes_prices/) surfaced live — venue floor and clip ceiling on
   the coin page, signature volatility, flow decomposition, tier-latency workability, caller
   track records with measured verdicts. Interesting market microstructure analysis on live
   charts is one of the whole points of the exercise.

3. **Self-modifying.** The Claude Agent SDK and Claude Code SDK (Python) embedded as JOSHI's
   resident core: an analyst that sees the current scene/coin and runs real analysis against
   the catalog and the analysis/ tree, and a developer lane that can edit JOSHI's own code
   under git discipline. JOSHI grows from inside.

4. **Honesty stays structural, never verbose.** The evidence discipline (absence stated,
   provider claims labeled, refusals that explain themselves) lives in chips, dashes, and
   one-hover provenance — never in paragraphs on cards. The copy-pass rule is permanent.

## The operating rules this pins

- The operator's 3-5-minute navigation verdict is the UX bar. "Aggressively unusable" was a
  design verdict, not a bug list; parity of density and immediacy is the target, and fixing
  defects one by one does not reach it.
- The primary agent walks every screen (browser harness) before the operator sits down. She
  does QA willingly, but never as the first person to discover a wall.
- Scope-backs she offers under frustration (the "$BOOBUS" boop-loop) are rescue maneuvers,
  not the vision. When delivery falls short, the fix is delivery, not shrinking the plot.
