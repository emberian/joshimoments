# Attention fixtures

`study-ready.valid.json` is a strict `joshi.attention.dataset.v1` example. It deliberately
contains:

- one exact Pump callout occurrence with an exact large numeric lexeme and separately quarantined
  retrospective peak multiple;
- two same-handle identity versions, only one of which was known at the event cutoff;
- an adapter-selected, event-bound view of a slot- and wall-valid wallet-cluster *hypothesis*, not
  a copy of ecology's full artifact or a canonical entity;
- a non-exclusive territory assertion;
- provider-presentation bindings (scene, view/presentation digests, session, policy);
- all five required callout mark families plus presentation, with unknown history represented as
  missing rather than zero;
- separately covered audience-overlap intersection and denominators;
- one measured response and one source-loss-censored response; and
- a prospective candidate census/risk set terminated by a duplicate-coin competing event.

`adversarial-mutations.v1.json` applies one mutation at a time to that dataset and names the exact
validation class expected. The offline test also constructs revision/deletion and follow-removal
cases: an edit/delete must retain and supersede prior revisions, while a removed follow edge needs
two complete comparable snapshot boundaries, an exact earlier membership occurrence, and no
intervening gap.

All names, wallets, mints, digests, clocks, counts, and outcomes are synthetic. These fixtures are
contract tests, not empirical evidence about Pump, callers, communities, or returns.
