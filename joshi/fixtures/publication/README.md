# Projection publication vectors

`publication_vectors.json` is the closed V1 conformance manifest for durable finalized projection
publication. The three `*_v1.json` files retain the complete compact JSON records whose bytes are
rebuilt by the Rust test (the conventional final newline is excluded from the record). Decimal
quantities are JSON strings. Every digest is lowercase SHA-256. The tests compare exact artifact,
publication, and cockpit bytes; compare byte lengths and digest domains; and independently
canonicalize the manifest.

The crash rows describe visibility, not simulated storage internals. `prior_stale` means a
complete prior append-only cockpit selection remains available with explicit stale state.
`newQueryable` means the new projection publication is already immutable and retrievable by an
exact ID/digest query even if the later cockpit-head append did not commit.

Do not update a golden merely because serialization changed. A change requires an intentional
contract/schema decision, regenerated bytes, digest review, and synchronized consumer vectors.

`cockpit_v2_resolved_source_facts_input_v1.json` is the canonical public source-fact closure a
store adapter passes to the pure V2 preparer. `cockpit_v2_head_v1.json` pins the append-only head
for that resolved input's frozen V2 publication body. Both are semantic/unverified vectors, never
durable receipts.
