# Scientific-memory adversarial fixtures

These fixtures are semantic occurrence schedules. They contain no provider credentials, wallet
material, transaction, fill, or execution claim. Replay must preserve the immediately durable act
when presentation capture fails, refuse scene-qualified research until a matching presentation
occurrence arrives, retain corrections/ontology versions without rewriting history, and keep
outcome-hidden reconstruction separate from retrospective interpretation.

`goldenChain` freezes one nonempty exact semantic walk from a scene/presentation-bound act through
a bounded episode, hidden replay, terminal session, partial knowledge closure, and explicit missing
outcome. It is intentionally unverified semantic data; store receipts are private store artifacts.
